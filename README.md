# Drug Dissolution Profile Analyzer

A Python-based pharmaceutical analysis project for evaluating and comparing in-vitro dissolution profiles of two tablet formulations.

## Objective

To analyze drug-release profiles over time and compare formulations using dissolution efficiency (DE) and time to 80% drug release (T80).

## Analysis Performed

- Created dissolution profile data
- Plotted drug release versus time
- Calculated dissolution efficiency
- Determined T80
- Compared two formulations
- Interpreted dissolution behavior

## Results

| Parameter | Formulation A | Formulation B |
|---|---:|---:|
| Dissolution Efficiency | 64.33% | 56.79% |
| T80 | 45 min | 60 min |

Formulation A showed faster and greater drug release than Formulation B in the simulated dataset.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Important Note

The dataset used in this project is simulated for educational and portfolio demonstration purposes. It does not represent experimental laboratory data.

Actual pharmaceutical dissolution comparisons require validated experimental data and appropriate statistical/similarity analysis where applicable.
